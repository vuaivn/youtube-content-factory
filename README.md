# YouTube Content Factory

Ứng dụng web chạy trên Windows: quản lý kênh YouTube, playlist, kho tài nguyên (hook / chuyện / outro / video shot / nhạc nền), kho chữ thumbnail + SEO; tự dựng video dài (giọng đọc + nhạc nền có fade + hình + phụ đề in sẵn + màn đen) và upload lên YouTube; chạy chuỗi nhiều playlist theo lịch, mỗi lúc một kênh.

- Không cần `npm install` — chỉ cần **Node.js 22.5+** và **ffmpeg**.
- Hướng dẫn cài đặt đầy đủ: **[CAI-DAT.md](CAI-DAT.md)**
